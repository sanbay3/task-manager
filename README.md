# タスク管理アプリ

## 概要

優先度・カテゴリー・期限を付けてタスクを管理できるタスク管理アプリです。
検索・絞り込み・並び替えで目的のタスクをすぐに見つけられます。
タスクはブラウザのlocalStorageに保存されるため、ページを再読み込みしても消えません。

## 機能

- タスクの追加（タイトル・優先度〔高 / 中 / 低〕・カテゴリー〔仕事 / 個人 / 学習 / その他〕・期限）
- 完了 / 未完了の切り替え
- タスクの編集（一覧上でその場で編集。Escキーでキャンセル）
- タスクの削除（削除後4秒以内なら「元に戻す」で復元可能）
- 完了済みタスクの一括削除
- キーワード検索
- 状態（すべて / 未完了 / 完了済）・優先度・カテゴリーでの絞り込み
- 並び替え（作成順 / 期限順 / 優先度順）
- 期限切れの未完了タスクを強調表示
- 未完了件数 / 全件数の表示
- localStorageによるデータ永続化
- モバイル対応のレスポンシブデザイン

## 使用技術

- HTML
- CSS（カスタムプロパティ / アニメーション / メディアクエリ）
- JavaScript（フレームワーク不使用のバニラJS）
- localStorage
- デプロイ: Cloudflare Pages
